description: How you can contribute to Sabre
---

Contribution is not yet available for Sabre as it is still an experimental project. Once a version `x.x.x` language can be shipped, contribution will become available. Sabre can be [built natively](./project/development) for those that want to get their hands dirty.

> **Note**: The `x.x.x` version is currently arbitrary to denote that contribution will come, just once the project is stable enough to accomodate doing so.
