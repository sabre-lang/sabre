## Rename Alert

The Talos programming language has now been renamed to Sabre since `v0.3.1-stable` following community recommendation. This release is purely transient other than a few minor bug fixes since the last release.

---

## Bug Fixes

<h4>Package / sabre</h4>

- Moved: Renamed the project from Talos to Sabre following community recommendation.

<h4>Toolkit / sabre run</h4>

- Added: The core executable now includes address sanitizer support although this is still experimental and can only be enabled when building from source.
