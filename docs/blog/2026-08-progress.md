## Status Update

August has been a whirlwind in development for Sabre. Most notably, with release [`v0.2.0`](/blog/sabre-v0.2.0) comes the culmination of the past few months of rework into a more cohesive and expansive project. At this stage, the final bit of work plus a few extras to complete are the following:

- [ ] Better Formatter Support
- [ ] Implement Further Testing
- [ ] More Language Server Features

After all this it will be time to start implementing the builtin crates!

## Upcoming Work

For now the next goal is the [`v0.3.0`](/blog/sabre-v0.3.0) release which will include the hardening of Sabre builtins and syntax. Since this upcoming release will include numerous bug fixes and changes to the builtin values, it needs a minor version bump instead of a patch.
