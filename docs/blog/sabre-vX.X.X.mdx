## Bug Fixes

<h4>Toolkit / sabre run</h4>

- Fixed: Applied better peep-hole optimization to bytecode to reduce the total register moves required.
- Fixed: Improved performance of internal hash-maps using `Symbol::Value` as keys through bypassing equality checking.
- Fixed: Optimized internal `Member::Storage` retrievals by caching reference descriptors after native method construction.
- Fixed: Prioritized feedback checks for validness first over invalidness. This allows skipping unnecessary exception generation.
- Fixed: Object headers were not being cached properly when executing garbage collection causing crashes. Now reachability is toggled correctly.
- Fixed: Minor bug with internal flags not toggling properly. This cause `String` symbols to not be saved but now they are hashed and saved.
