## Bug Fixes

<h4>Package / crates</h4>

- Moved: Removed the `sabre:codec` crate as it is currently unnecessary.

<h4>Package / vscode</h4>

- Fixed: The settings open command now correctly opens the user-settings for Sabre.

<h4>Toolkit / sabre bundle</h4>

- Fixed: Removed unnecessary copies of the base binary to be bundled improving bundling speed.

<h4>Toolkit / sabre format</h4>

- Added: Implemented the `--config` option for defining a common manifest for formatting configuration.
- Moved: Removed the `--json` flag for formatting since it requires diffing of two strings to implement.

<h4>Toolkit / sabre run</h4>

- Added: Implemented the `--env` option for defining embeddable environment variables.
- Fixed: Improved reading speed of files by eliminating an erroneous copy into internal storage.
- Added: Prepared foundations for the `Buffer` builtin type to be used for fixed-length contiguous sequences of bytes.
- Fixed: Commit [2ad55c4](https://github.com/sabre-lang/sabre/commit/2ad55c486d0640991a62094e76216fe6600c4b96#diff-0b8ad881c61b65b7f80a7892e0d86fede39932100fd3ec7a22f023bccda24d08R166) introduced a `nullptr` stack reference for jitted functions. This has been reverted.

<h4>Toolkit / sabre test</h4>

- Added: Implemented the `--seed` option can be used to define a randomization seed for testing.
- Added: Implemented the `--randomize` flag can be used to shuffle test ordering for all tests.
- Added: Implemented the `--outfile` option for defining a file to pipe testing reports to.
- Added: Implemented the `--reporter` option, however only the `text` reporter is currently implemented.
- Added: Implemented the `--bailout` option for setting a threshold of test failures to bail at.

<h4>Crate / sabre:env</h4>

- Added: Prepared the `env` crate for managing the process environment.
- Added: Implemented the `get` function for getting environment variables.
- Added: Implemented the `set` function for setting environment variables.
- Added: Implemented the `drop` function for deleting environment variables.

<h4>Crate / sabre:fs</h4>

- Moved: Renamed the `fsys` crate to `fs` for upcoming work with the builtin crates.
- Added: Implemented the `read_file` method for reading files to a `Buffer` value.
- Added: Implemented the `read_text` method for reading files to a `String` value.
- Added: Implemented the `write_file` method for writing files with a `Buffer` value.
- Added: Implemented the `write_text` method for writing files with a `String` value.
- Added: Implemented the `remove_entry` method for removing entries from the filesystem.
- Added: Implemented the `temp_file` method for generating temporary files.
- Added: Implemented the `exists_file` method for checking a file entry exists.
- Added: Implemented the `exists_entry` method for checking a any filesystem entry exists.

<h4>Crate / sabre:os</h4>

- Added: Prepared a stub crate for the `os` crate for operating system interface methods.
